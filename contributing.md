
# Contributing to Chalk

Thank you for your interest in contributing to Chalk!

We welcome contributions that improve Chalk's functionality, documentation, performance, and developer experience.

## Getting Started

### Prerequisites

- Node.js 22 or later
- npm
- Git

### Set Up the Project

1. Fork the repository.
2. Clone your fork:

```bash
git clone https://github.com/YOUR_USERNAME/chalk.git
cd chalk
```

3. Install dependencies:

```bash
npm install
```

## Running Tests

Before submitting your changes, run:

```bash
npm test
```

This command runs:
- XO linting.
- Automated tests using Node.js test runner.
- TypeScript declaration checks.

## Project Structure

- `source/` - Chalk implementation and source code.
- `test/` - Automated tests.
- `examples/` - Usage examples.
- `media/` - Project images and assets.
- `benchmark.js` - Performance benchmarks.

## Submitting Changes

1. Create a new branch for your changes.
2. Make your changes following the existing code style.
3. Add or update tests when necessary.
4. Run `npm test` to verify your changes.
5. Commit your changes with a descriptive commit message.
6. Push your branch to your fork.
7. Open a pull request against the Chalk repository's `main` branch.

Please provide a clear description of your changes and explain why they are useful.

## Code of Conduct

Thank you for helping improve Chalk!
